# Paprika Messenger support

Open a [repository issue](https://github.com/newbiesitl/paprika-messenger/issues) with the plugin/service version, redacted error and expected result. Issues are public: never include private board messages, authentication tokens, API keys, callback keys, passwords or personal account details.

Current source: plugin **1.3.10**, service **0.5.6**. See [setup](../docs/SETUP.md), [security](../docs/SECURITY.md), [privacy](PRIVACY.md) and the [MIT license](../LICENSE). Each owner operates their own private service. Use the hosting provider’s support for account, billing and hosting questions.
