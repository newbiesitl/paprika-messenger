# Paprika Messenger 1.3.9 installation kit

The complete private account ZIP includes both Paprika skills, service source 0.5.6, optional Dot service-type setup, and the original red Paprika PNG for light and dark listing/composer icons.

This owner-neutral kit contains no shared endpoint, App ID, OAuth credential or message database. Follow [account installation](../../docs/ACCOUNT-PLUGIN.md) to bind the owner's verified existing App and save one complete private package through Plugin Creator. Upgrades can read that binding from an existing standalone package, including host-normalized native manifests.

Verify `SHA256SUMS` before extracting. The package and optional local install use the same version. Authenticated reads, installation scope, each supported client and the displayed listing icon require separate checks. Updating the package does not deploy the bundled service source. Historical archives keep their original checksums.
