# Paprika Messenger (Private)

Plugin version 1.3.5, bundled service version 0.5.4. This one package includes setup, messaging skills and the complete reusable service source. Open the onboarding workflow to check Sites and reuse your service or deploy a new private instance. Installing skills alone does not deploy or connect a service. Connect the same provisioned service plugin in each participating client; receiving chats opt in to notifications separately.
